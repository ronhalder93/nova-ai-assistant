# Nova AI Cloud Brain

This Space runs `Qwen/Qwen2.5-0.5B-Instruct` as a small chat model.

- The model weights are fetched by Hugging Face when the Space starts.
- The first startup can take several minutes and needs internet access.
- Free ZeroGPU access has account eligibility and daily quota limits.
- Set `MODEL_ID` in Space variables to change the model ID.
